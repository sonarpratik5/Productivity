These are window captures of the real interface, not recreated mockups. The sample build was made in a temporary source copy with a separate bundle identifier, an in-memory activity repository, a mock tracker, and a temporary calendar store. It used synthetic app sessions, companion streams, goals, pins, focus-session history, and a fictional display name. The production app source was not modified for this documentation change.

All displayed productivity ratios, durations, streaks, and goal counts are illustration data, not user outcomes or performance benchmarks. Research statistics in the README come from the cited papers, independently of these screenshots.

The banner in `../assets/hero.svg` is a decorative vector asset based on the app's existing route-shaped brand mark; it is not an app screenshot.
